
# Distributeur automatique de tickets bancaires

## Présentation

Application console développée en C# avec .NET permettant de simuler un distributeur automatique de tickets dans une banque.

## Types d'opérations

- Versement (V)
- Retrait (R)
- Informations (I)

## Fonctionnalités

- Attribution de tickets selon le type d'opération.
- Gestion de plusieurs clients.
- Plusieurs opérations possibles pour un même client.
- Réutilisation du même ticket pour un même type d'opération.
- Gestion de trois compteurs indépendants.
- Sauvegarde des compteurs dans le fichier fnuméro.txt situé dans le dossier temporaire du système.
- Contrôle des saisies utilisateur.
- Commandes STOP et FIN.
- Affichage du récapitulatif des clients et de leurs tickets.

## Technologies utilisées

- C#
- .NET 10
- Application console
